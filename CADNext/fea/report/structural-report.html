    Материал

    Типичные свойства, не допускаемые значения (A/B-basis). Запас — инженерная оценка симулятора, не сертификация.

    Критерий

    Нет текучести при эксплуатационной нагрузке (CS-23.305(a)); нет разрушения при расчётной = ×1.5 (CS-23.303, STANAG 4671). Погрешность — GCI по трём сеткам (Celik et al., 2008), порядок не выше теоретического для TET10.
