    Моды

    Эффективная масса — доля массы свободных степеней свободы, которую мода вовлекает при поступательном возбуждении основания вдоль оси. Моды сопоставляются между сетками по порядку.

    Сходимость по сетке

    Погрешность частоты — GCI по трём сеткам (Celik et al., 2008), порядок не выше теоретического 4 для собственных значений TET10. Жёсткая заделка замедляет сходимость — наблюдаемый порядок около 2 это нормально.
