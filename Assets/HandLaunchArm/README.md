# Руки для ручного запуска

Основа: [fps arms (rigged only)](https://opengameart.org/content/fps-arms-rigged-only), para / MakeHuman team. Лицензия [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Платные модели не использованы.

## Файлы

- `hand-launch-arm-left.usdz`, `hand-launch-arm-right.usdz`: отдельные человеческие руки, по 65 216 треугольников и 24 сустава. В каждом файле есть анимация раскрытия и сгибания пальцев.
- `rig-left.json`, `rig-right.json`: суставы, анатомические оси сгиба, исходные имена костей и точки для проверки контакта.
- `grips.json`: измеренные хваты семи аппаратов, позы суставов и результаты нативной проверки.
- `previews/`: крупные планы, вид оператора, хват и раскрытие пальцев после выпуска.
- `sources/original/`: исходные Blender, FBX, текстура и оригинальный архив автора.
- `sources/*.usda`: редактируемые USD-источники экспорта.

Геометрия не уменьшалась. К исходной анатомической сетке применено подразделение поверхности уровня 2; сохранены UV, исходная текстура 1024×1024 и все исходные веса кожи, до семи влияющих суставов на вершину. Размер кистей постоянный: под аппарат меняется поза, а не масштаб всей руки.

## В симуляторе

Хват измеряется по геометрии выбранного аппарата. Сечения крыла и фюзеляжа получаются пересечением треугольников с плоскостью; контроль контакта учитывает соседние сечения. Пальцы сгибаются согласованно по трём фалангам, пока не достигают поверхности. Плечи находятся по бокам камеры, локти решаются через IK.

Для eBee используются две руки на передних кромках, для UX11 — правая рука на правом крыле, для Raven — хват фюзеляжа правой рукой. Puma держатся двумя руками с разведёнными точками контакта. Для экспериментальной EPFL Delta Wing выбран хват правого крыла по геометрии модели; это симуляторная поза, а не подтверждённая процедура производителя.

На старте раскрываются пальцы и выполняется движение руки вперёд и вниз. Руки после выпуска не следуют за улетевшим аппаратом. При смене аппарата хват вычисляется заново.

Старая статичная скульптура и упрощённая замена из примитивов исключены из приложения.

## Повторная сборка

Нужны Blender 4.5+ и системные инструменты USD macOS. В Blender выключено исполнение скриптов из входного файла:

```sh
Blender --background --factory-startup --disable-autoexec --python Tools/HandLaunchArmAssets/build.py
swiftc DroneUAVDemo/Scene/AdaptiveHandLaunchRig.swift Tools/HandLaunchArmAssets/fit.swift -o /tmp/fit-hands
/tmp/fit-hands DroneUAVDemo/Resources/Models/UAVModels Assets/HandLaunchArm Assets/HandLaunchArm/previews
```

После экспорта обновить файлы в `DroneUAVDemo/Resources/Models/HandLaunchHands/`. Манифест содержит контрольные суммы USDZ. `usdchecker-*.txt` содержит результат проверки пакетов Apple USD; `grips.json` — измеренные значения погрешности контакта, положения плеч и угла запястья.
